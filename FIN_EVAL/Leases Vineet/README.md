# ePulse Tracker

### Project Setup
```bash
# Clone Git Repo


# Install Node Dependencies
npm install

# Run Dev Server
npm run dev

# Build app
npm run build
```

### Technology Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Radix UI / Shadcn
- Lucide Icons
- DnD KIT (Drag and Drop)
